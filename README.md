# 支援員成長プラットフォーム 🏢

就労支援事業所向けの業務管理・支援員育成プラットフォームです。

## 機能

### 👷 支援員ダッシュボード
- 📊 KPIトラッカー（営業活動・成約管理）
- 📋 利用者ステータス管理
- 📝 日報・週報
- 💬 社内スレッド
- 📅 スケジュール管理
- 🌱 1on1 メンタリング
- 🤖 本部への質問（AI + NotebookLM連携）

### 👔 管理者ダッシュボード
- 🏢 全事業所サマリー
- 📊 営業KPI（事業所別比較）
- 📒 利用者台帳
- 👥 支援員・KPI管理
- 📑 行政申請・利用実績・支援記録

### 🎓 利用者ポータル
- マイページ（卒業ステップ・学習記録）
- 体調チェックイン
- 面談記録閲覧
